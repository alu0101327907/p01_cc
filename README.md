# Práctica 1 — Simulador de un Autómata con Pila

## Tipo de autómata implementado

**APf**: autómata con pila con **aceptación por estado final**.

Una cadena se acepta si, tras consumir toda la entrada, el autómata se
encuentra en algún estado de `F`. La pila puede quedar con cualquier contenido.

## Requisitos

- Compilador con soporte C++17 (g++ ≥ 9, clang++ ≥ 10).
- `make` (GNU Make).
- Linux / macOS / WSL.
